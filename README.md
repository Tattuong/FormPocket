# FormPocket

Fill shipping, invoice, and personal details faster. Profiles and templates stay on this device.

Package: `com.FormPocketMNG.FormPocket`

Remote config: [N295.json](https://api2.blwsmartware.net/N295.json) — `disable=1` hides Google Play Billing popups only. Shop stays open for coin unlocks.

| Product ID | Type |
| --- | --- |
| `fp_pack_1` … `fp_pack_10` | Consumable coins |
| `fp_remove_ads` | Non-consumable |
| `fp_pro` | Non-consumable extra profiles and templates |

Three free profiles and two free templates. Copy one field or a filled template. Sensitive fields stay masked, and a PIN can lock the app. No account.
